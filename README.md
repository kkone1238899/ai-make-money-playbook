**解决什么问题**：网上"AI 搞钱"帖 99% 是鸡汤。这个库只收**带真实数据**（收入 / 时间 / 用户数）的实战复盘，每条拆成四问：**怎么做 → 花多少 → 能不能复制 → 坑在哪**。先看"可复制性"，再看"成本门槛"，对上你手里的资源再动手。

### 1. 没投流、没买外链，一个新词站 72 小时 $5,480 ✅

- **人物/来源**：@xuxuanzhou（绪轩）X Article，2026-10-19；[原文](https://x.com/xuxuanzhou/status/2112129349071831259)（69,787 浏览 / 1590 收藏）
- **核心数据**：72 小时 $5,480；首周 558 单、$6,434；393 付费用户；退款率 3.9%；API 成本约 1 万人民币
- **怎么做**：① TikTok 冒出新梗（Bulin 47 说唱），当天买域名 ② 上线单功能 AI 视频站（上传照片生成 19 秒说唱视频），支付/积分/登录/埋点复用老站模板，真正写代码 5 小时 ③ 吃 SEO 新词红利（梗冒头到 Google Trends 见顶约 4 天）④ 按次收费 $9.99/条（92% 订单），不做订阅 ⑤ 先上线再改（首日 23 次提交），别让 AI 乱加限额和自动判定
- **成本门槛**：钱：域名 + API 约 1 万人民币；技术：中（能独立搭全栈单页站）；时间：5 小时写代码 + 持续迭代。核心是"快和早"的执行力
- **可复制性**：高。85% 的钱在头 72 小时进来——方法论就是"新梗出现 24 小时内上线吃 SEO"，模板预置后边际成本极低
- **风险**：强依赖热点窗口（4 天见顶），错过即归零；单功能站无护城河，跟风者极快；AI 视频 API 成本随量涨，定价要覆盖

### 2. TypingMind：给 ChatGPT 换了个更好用的 UI，7 天 $22.7K ✅

- **人物/来源**：Tony Dinh @tdinh_me（越南独立开发者）；[当事人复盘](https://news.tonydinh.com/p/making-22k-in-7-days-the-story)

- **怎么做**：① OpenAI 放出 ChatGPT API 当天注册域名（域名还是 ChatGPT 给起的）② 周末 4 天写出 MVP——差异化：比网页版快、可搜索历史、自定义角色、用户自带 API Key（无月费）③ 每天加功能、每次加功能就发一条推（"每次加功能就发推就是我全部的营销策略"）④ 定价 $9 起随功能涨到 $39，一次性买断 ⑤ Product Hunt 冲榜 #1 当天再 +$5K ⑥ 后续做 B2B 团队版变经常性收入主力
- **成本门槛**：钱≈0；技术：前端 UI 功底；时间：MVP 4 天。关键变量是 BYOK 零边际成本模式（用户自带 Key，token 账单不经过自己）
- **可复制性**：高（模式）/ 中（时机）。BYOK 把 AI 产品最大的成本黑洞消掉，薄壳+快是个人开发者最能跟风吃的打法；但"套壳+体验碾压"的窗口期已过，护城河只在"新 API/新模型发布那 72 小时"
- **风险**：纯 wrapper 无技术壁垒，官方补齐功能即被收割；套壳命门在平台政策；他复盘中两次 AI 产品合计只赚约 $100——"5,000 赞的 launch 推"也带不动没需求的产品

### 7. ScreenshotOne：截图 API，一个人做 $20K MRR 的"无聊 API"生意 📝

- **怎么做**：① 选"无聊但刚需"的开发者工具：网页截图 API（每个 SaaS 的 OG 图、缩略图、PDF 归档都要用）② 自建浏览器集群做质量控制（比直接调无头浏览器更稳更快，形成小壁垒）③ 定价按量订阅，开发者自助开通，无销售团队 ④ 获客只做两件事：SEO（"screenshot api" 类高意图词）+ 社区/社交媒体，靠长期主义熬出来
- **成本门槛**：钱中（浏览器集群服务器约 $5.5K/月起步）；技术中高（无头浏览器集群、队列、缓存、限流）；时间：从 0 到 $1K MRR 同类 API 通常 2–4 个月

- **风险**：获客是最大难点（krasun 原话"unimaginably tough"），SEO 起量慢；云厂商下场做同类基础能力会被碾压
